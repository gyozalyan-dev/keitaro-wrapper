# Keitaro Wrapper Enterprise (Monolith Edition)

Автономный веб-сервис для управления рекламными кампаниями и распределения трафика в 
трекере Keitaro. Спроектирован в виде компактного однофайлового монолита с энергонезависимым 
хранением данных.

## Стек технологий
* **Backend:** Python 3.13, FastAPI, Uvicorn
* **База данных:** SQLAlchemy ORM + SQLite (`keitaro_sandbox.db`)
* **Frontend:** Встроенный адаптивный интерфейс (HTML5, CSS3, Vanilla JS)

## Реализованный функционал
1. **Создание кампаний (Часть 1):**
   * Автоматическая подстановка префикса `test_gyozalyan_` к названию кампании.
   * Привязка списка ГЕО и стартового оффера со 100% весом.
2. **Редактор потоков и математика весов (Часть 2):**
   * Динамическое добавление (`ADD`), мягкое удаление (`REMOVE`) и восстановление (`BRING BACK`) офферов.
   * Точный пересчёт весов долей между активными офферами без ошибок округления (50/50, 33/33/34, 25/25/25/25).
   * Защита от удаления последнего активного оффера в потоке и контроль несохранённых изменений через индикацию кнопки `PUSH TO KT`.
   * Интерактивные уведомления при граничных сценариях.

## Быстрый запуск (в один такт)

1. Установите зависимости:
   ```bash
   pip install fastapi uvicorn sqlalchemy python-multipart
   ```

2. Запустите сервер:
   ```bash
   python main.py
   ```
   *(или через Uvicorn: `python -m uvicorn main:app --reload --port 8000`)*

3. Откройте в браузере: **`http://127.0.0.1:8000`**
